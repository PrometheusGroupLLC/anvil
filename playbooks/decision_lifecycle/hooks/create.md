# Create Decision Tension

Record a new unresolved question as a decision in `tension`.

Read the existing decisions registry and nearby decision definitions before writing so the new tension is distinct. Fill `definition.md` with the question, context, domain tags, lineage, and related links. Do not add a resolution yet.

Use the engine for lifecycle movement. The directory and initial transition have already been scaffolded by `begin(artifact_type: "decision")`; edit only the decision content files.
