# Capture Observation

Record a new observation as a learning in `observation`.

Read the existing learnings registry and nearby learning definitions before writing so the new observation is distinct — not a duplicate or subset of an existing one. Fill `definition.md` with the observation (what was noticed, stated plainly), the context (where, when, and how it was observed), the source (which reflection, spark, or direct observation surfaced it), and freeform domain tags for discovery. Do not add an interpretation yet.

Use the engine for lifecycle movement. The directory and initial transition have already been scaffolded by `begin(artifact_type: "learning")`; edit only the learning content files.
