# Revise Learning

Respond to review findings or apply an approved amendment.

Read `definition.md`, `review.md`, and `amendments.md`. Append a timestamped response in `review.md` with an explicit disposition for every finding. Use `Will address` or `Acknowledged, not addressing` and explain the reason.

If this is a review response, revise `definition.md` as needed. If this is an approved amendment application, update `definition.md` to reflect the approved amendment.
