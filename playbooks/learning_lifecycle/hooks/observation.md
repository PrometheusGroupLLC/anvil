# Review Observation

Review whether a learning in `observation` is a real, useful signal.

Check:

- Is the observation real and stated plainly?
- Is the context accurate and sufficient — which track, which phase, what circumstances?
- Is it distinct from existing learnings?
- Are domain tags useful for discovery?
- Is the source traceable to the work that surfaced it?

Write the review in `review.md`. Observation review validates the raw signal, not an interpretation, and does not freeze `definition.md`.
